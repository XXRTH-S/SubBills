# SubBill — รวมทุกค่าสมาชิก จัดการง่ายในที่เดียว

ขั้นแรก: ต้นแบบเว็บสำหรับมือถือ รองรับไทยและอังกฤษ ไม่ต้องติดตั้ง dependencies เพื่อเปิดแอป

## เปิดใช้งาน

```sh
npm start
```

เปิด http://127.0.0.1:4173 และทดสอบด้วย `npm test`

## ทำได้

- เพิ่มและแก้ไขบริการรายเดือน/รายปี พร้อมวันเริ่มเรียกเก็บและบัตร
- เพิ่มบัตรอ้างอิง ชื่อ ธนาคาร และเลขท้าย 4 หลัก ไม่เก็บเลขเต็มหรือ CVV
- เพิ่มบัตรระหว่างกรอกบริการ โดยรักษาข้อมูลฟอร์มเมื่อบันทึกบัตรสำเร็จ
- ดูยอดตามเดือน ค่าเฉลี่ยรายเดือน ยอดแยกบัตร และยืนยันจ่ายด้วยตนเอง
- แจ้งเตือนในแอปก่อนกำหนด 3 วัน / ย้อนหลัง 7 วัน อ่านทั้งหมดได้
- สลับ TH/EN และบันทึกข้อมูลใน localStorage ของเบราว์เซอร์

## ขอบเขตต้นแบบ

ไม่มีบัญชี ฐานข้อมูล เซิร์ฟเวอร์แจ้งเตือน หรือการเชื่อมธนาคาร การแจ้งเตือนคำนวณเมื่อเปิดหน้าและกลับเข้าแท็บ ไม่ทำงานเบื้องหลังขณะปิดเว็บ ข้อมูลจริงควรรอระบบบัญชีและการควบคุมสิทธิ์

ใช้เงินบาทและเวลาท้องถิ่นอุปกรณ์ ยอดเฉลี่ยรวมทุกบริการที่บันทึก วันสิ้นเดือนปรับตามเดือนสั้นโดยรักษาวันตั้งต้น รายปีคิดยอดเต็มเฉพาะเดือนต่ออายุ ยอดจ่ายแล้วต้องยืนยันเอง

ยังไม่มีทดลองใช้ฟรี พัก/ยกเลิกบริการ ลบข้อมูลรายรายการ ส่งออก กราฟย้อนหลัง และประวัติราคา/บัตรแยกแต่ละรอบ การแก้ไขบริการจะคำนวณประวัติใหม่ เหมาะสำหรับทดสอบ UX เท่านั้น ไม่ใช่บัญชีธุรกรรม

## ขั้นถัดไป

ทดสอบกับผู้ใช้: เพิ่มบริการแรกภายใน 1 นาที ระบุยอดเดือนนี้และบัตรที่ใช้ได้ เปรียบเทียบยอดตัดจริงกับค่าเฉลี่ยได้ และอ่านแจ้งเตือนได้ทั้งสองภาษา จากนั้นจึงเพิ่มระบบบัญชี ฐานข้อมูล ประวัติรอบเรียกเก็บ และงานแจ้งเตือนเบื้องหลัง

## ดีไซน์
พาสเทลลาเวนเดอร์ มิ้นต์ และพีช พร้อมแถบนำทางกระจกโปร่งแสง ใช้ Nunito และ Mali ที่เก็บใน assets/fonts พร้อมใบอนุญาต (ไม่เรียกบริการฟอนต์ภายนอก) เคารพการตั้งค่าลดการเคลื่อนไหวและมีสีพื้นสำรองเมื่อเบราว์เซอร์ไม่รองรับ blur


## หน้า Login ต้นแบบ
หน้าแรกเป็น Login ไทย/อังกฤษ มีแสดงหรือซ่อนรหัสผ่าน และข้อความอธิบายเมื่อกดเข้าสู่ระบบหรือลืมรหัสผ่าน ยังไม่เชื่อม Authentication และไม่ส่งหรือเก็บข้อมูลที่กรอก การทดลองเข้าหน้าแดชบอร์ดใช้ปุ่มแยก เก็บเพียงสถานะโหมดทดลองใน sessionStorage ออกได้จากไอคอนด้านบน ข้อมูลเดิมยังอยู่ใน localStorage และไม่ได้รับการป้องกันด้วยหน้า Login


## ความเป็นส่วนตัวและการป้องกัน
เพิ่มในหน้าตั้งค่า: ซ่อนยอดเงิน/เลขท้ายบัตร ส่งออกข้อมูล และล้างข้อมูลบนอุปกรณ์พร้อมยืนยัน ข้อมูลผิดรูปแบบจะถูกแยกจากการแสดงผลและหยุดการบันทึกเพื่อรักษาต้นฉบับไว้ให้ดาวน์โหลดกู้คืน การซ่อนยอดเป็นเพียงการซ่อนบนหน้าจอ ไม่ใช่การเข้ารหัสหรือควบคุมสิทธิ์

รายละเอียดสิ่งที่ทำแล้วและสิ่งที่ต้องทำก่อนเปิดจริงอยู่ใน SECURITY.md

เพิ่มหน้าสมัครสมาชิกและขอลิงก์กู้คืนรหัสผ่าน TH/EN พร้อมตรวจรหัสผ่านยืนยัน ขณะนี้ยังรอเลือกและเชื่อม identity provider จึงไม่สร้างบัญชีหรือส่งอีเมลจริง

## เตรียมฐานข้อมูลและนำเข้าข้อมูล

เตรียม target schema พร้อมกฎเจ้าของข้อมูลใน `supabase/schemas/01_core.sql` และตัวสร้าง preview นำเข้าข้อมูลใน `account-import.js` แล้ว ทั้งสองส่วนยังไม่เชื่อม UI หรือบริการจริง รายละเอียดการตั้งค่าและเกณฑ์ทดสอบอยู่ใน [docs/account-setup.md](docs/account-setup.md) การรัน `npm test` ตรวจการเตรียมข้อมูลนำเข้าได้ แต่ไม่ได้ยืนยัน RLS บนฐานข้อมูลจริง


ล่าสุด: เปลี่ยนหน้าบัญชีเป็น Google Login; email/password ผ่าน Resend จะเพิ่มภายหลัง ดูขั้นตอนใน docs/account-setup.md เซิร์ฟเวอร์อ่าน .env แล้ว แต่ต้องใส่ Publishable key และตั้ง Google provider ก่อนใช้งานจริง
